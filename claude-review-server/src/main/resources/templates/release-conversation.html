PR 코멘트 대화형 응답

기능 개요

PR에 @sparta 멘션으로 AI에게 질문하면 상세한 답변을 받을 수 있습니다. 기존 리뷰에 대한 질문, 코드 제안 요청, 새 리뷰 요청까지 가능합니다.

1

시나리오 1: 리뷰에 궁금한 점이 있을 때

가장 많이 사용하게 될 기본 시나리오
PR에 AI 리뷰가 달렸습니다

PR을 열면 AI가 자동으로 코드를 리뷰하고 코멘트를 남깁니다.

## 🤖 AI 코드리뷰

### 🔴 주의
- `UserService.java` 42번째 줄에서 NPE 위험이 있습니다.
  `user.getName()` 호출 전 null 체크가 필요합니다.
리뷰 내용에 질문을 남깁니다

PR 코멘트에 @sparta를 멘션하고 질문을 적습니다.

@sparta NPE 위험이라고 했는데, Optional을 쓰는 게 나을까요?
아니면 그냥 null 체크 if문이 나을까요?
AI가 질문에 답변합니다

잠시 후 AI가 페르소나(멘토/시니컬) 톤에 맞춰 답변을 달아줍니다.

## 💬 AI 답변

이 코드에서는 `Optional`보다 null 체크가 더 적합합니다.

```java
// 추천 방식
if (user != null) {
    return user.getName();
}
return "알 수 없음";
```

`Optional`은 반환값이 없을 수 있음을 명시할 때 쓰는 게 좋고,
지역 변수의 null 방어에는 전통적인 체크가 더 깔끔합니다.
2

시나리오 2: 특정 코드 라인에 질문하고 싶을 때

라인 단위 정밀 질문
AI 리뷰의 특정 라인 코멘트에 답글을 답니다

리뷰 코멘트(특정 줄에 달린 코멘트)에 답글을 달아 질문합니다.

@sparta 이 줄에서 제안한 리팩토링 예시 코드를 보여줄 수 있어?
해당 코드 컨텍스트를 기반으로 답변합니다

AI가 해당 파일의 diff와 리뷰 내용을 참고하여 구체적인 예시 코드를 제시합니다.

3

시나리오 3: 아직 리뷰가 없는 PR에서 멘션할 때

PR 업데이트 안내
PR에 아직 AI 리뷰가 없는 상태에서 멘션합니다 
@sparta 이 PR 코드 리뷰해줘
AI가 안내 메시지를 남깁니다

전체 리뷰는 PR opened/synchronize 이벤트에서만 자동 생성됩니다. 멘션으로는 대화형 Q&A를 제공합니다.

전체 리뷰는 PR을 업데이트(push)하면 자동으로 제공됩니다.
궁금한 부분에 대해 멘션으로 질문을 남겨 보세요.

작동 방식

트리거PR 코멘트에 @sparta 멘션 (대소문자 구분)
즉시 인식멘션 감지 시 👀 이모지가 즉시 추가됩니다
응답 시간보통 10~30초 내로 코멘트가 등록됩니다
페르소나멘토 모드 / 시니컬 모드가 번갈아 적용됩니다
대화 히스토리최근 10개까지 이전 Q&A를 참고하여 일관된 답변을 제공합니다
지원 코멘트일반 코멘트(issue_comment) + 라인 리뷰 답글(review_comment)

사용 팁

질문은 구체적으로

@sparta 이 코드 어떤가요? 보다 @sparta 42번 줄의 NPE 위험을 어떻게 고치는 게 좋을까요? 처럼 구체적으로 물어보면 더 정확한 답변을 받을 수 있습니다.

연속 질문 가능

한 PR에서 여러 번 질문할 수 있습니다. AI가 이전 대화 내용을 기억하여 맥락에 맞는 답변을 제공합니다.

멘션만 있으면 스킵

@sparta만 단독으로 적히면(질문 내용이 없으면) 응답하지 않습니다. 반드시 질문 내용을 함께 적어주세요.

적용 방법

최신 ai-review.yml을 다운로드하여 팀 레포의 .github/workflows/ 에 덮어쓰세요.
이미 REVIEW_SERVER_URL과 REVIEW_SECRET이 등록되어 있다면 추가 설정 없이 바로 사용할 수 있습니다.

Spring Boot 3.5 + Spring AI 1.0 + Java 21
