워크플로우 설치/업데이트 가이드

AI 코드리뷰를 팀 저장소에 적용하는 방법

빠른 설치 (3단계)

1
YAML 파일 다운로드

아래 버튼을 클릭하여 최신 워크플로우 파일을 다운로드하세요.

2
저장소에 파일 추가

다운로드한 파일을 팀 저장소의 아래 경로에 추가하세요:

your-repo/
  .github/
    workflows/
      ai-review.yml    ← 이 위치에 파일 추가
3
GitHub Secrets 등록

저장소 Settings → Secrets and variables → Actions → New repository secret:

Secret 이름값설명
REVIEW_SERVER_URL https://review.example.com 리뷰 서버 주소
REVIEW_SECRET 제공받은 시크릿 키 인증용 공유 키

업데이트 방법

새 기능이 추가되면 이 페이지에서 최신 YAML을 다시 다운로드하여 기존 파일을 덮어쓰세요.

업데이트 절차 
1. 이 페이지에서 최신 ai-review.yml 다운로드
2. 저장소의 .github/workflows/ai-review.yml 을 새 파일로 교체
3. 커밋 & 푸시
4. 다음 PR부터 새 기능이 자동 적용

Secrets(REVIEW_SERVER_URL, REVIEW_SECRET)은 변경할 필요가 없습니다.

이 워크플로우가 하는 일

기능동작
PR 자동 리뷰 PR을 열거나 업데이트하면 AI가 코드를 분석하여 코멘트를 등록합니다
이전 피드백 검증 PR 업데이트 시 이전 리뷰에서 지적한 사항의 반영 여부를 확인합니다
대화형 Q&A PR 코멘트에 @sparta 질문내용을 적으면 AI가 답변합니다

문제 해결

증상확인 사항
PR에 리뷰가 안 달림 1. .github/workflows/ai-review.yml 파일이 있는지 확인
2. GitHub Actions 탭에서 워크플로우 실행 로그 확인
3. REVIEW_SERVER_URL, REVIEW_SECRET Secrets가 등록되어 있는지 확인
@sparta 멘션이 안 먹힘 일반 코멘트(리뷰 코멘트 아님)에 @sparta를 적었는지 확인하세요.
리뷰 코멘트(review comment)에도 동작합니다.
diff가 너무 작다고 스킵됨 변경사항이 100바이트 미만이면 자동 스킵됩니다.
의미 있는 변경을 PR에 포함하세요.

Spring Boot 3.5 + Spring AI 1.0 + Java 21
