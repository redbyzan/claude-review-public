리뷰에 액션 버튼 추가

무엇이 바뀌었나요

AI 리뷰 코멘트에 업데이트 가이드, 질문하기 버튼이 추가되었습니다.
리뷰를 읽고 나서 "다음에 뭘 해야 하지?"라고 고민할 필요 없이,
버튼을 클릭하면 바로 다음 단계로 이동할 수 있습니다.

시나리오 — 리뷰를 받은 수강생의 경험

Before — 버튼이 없을 때 
수강생이 PR에 AI 리뷰 코멘트를 받음
  → 리뷰를 읽고 권장 개선사항을 확인
  → "워크플로우를 어떻게 업데이트하지?" → 구글링 or 슬랙 질문
  → 답변을 기다리는 동안 개발 흐름이 끊김

문제: 리뷰를 읽었지만 "다음 행동"이 명확하지 않음
After — CTA 버튼 추가 
수강생이 PR에 AI 리뷰 코멘트를 받음
  → 리뷰를 읽고 권장 개선사항을 확인
  → 리뷰 중간에 [업데이트 가이드 확인] 버튼 클릭 → 가이드 페이지로 이동
  → 리뷰 하단에 [워크플로우 업데이트] [질문하기] 버튼
  → 버튼 하나로 다음 행동 즉시 실행

효과: 리뷰 → 액션 전환이 1클릭으로 단축

버튼은 어디에 나오나요

모든 AI 리뷰 코멘트에 자동으로 추가됩니다. 별도 설정이 필요하지 않습니다.

어떻게 만들었나요

GitHub PR 코멘트에서는 일반적인 HTML 버튼이나 JavaScript를 사용할 수 없습니다.
대신 Shields.io 뱃지 이미지를 버튼처럼 사용합니다:

GitHub Markdown에서 HTML <button> 사용 불가
→ 이미지 + 링크 조합으로 버튼 효과
→ Shields.io: URL 파라미터로 뱃지 동적 생성
→ 결과: PR 코멘트에서 실제 버튼처럼 보이고 작동

버튼 문구, 색상, 링크 URL은 서버 설정에서 관리하므로
코드 수정 없이 운영 중에 변경할 수 있습니다.

버튼이 항상 나온다고 어떻게 보장하나요

3계층 방어 구조로 최소 1개 이상의 버튼 세트가 항상 노출됩니다:

계층방식보장
하단 CTA 문자열 덧붙이기 (AI 응답 무관) 100%
중간 CTA 정규식 매칭 (AI 응답 포맷 의존) best-effort
모니터링 Prometheus 메트릭으로 삽입 성공/실패 추적 장애 조기 감지

수강생에게 어떤 의미인가요

리뷰 후 다음 행동이 명확해집니다

리뷰를 읽은 후 바로 워크플로우를 업데이트하거나,
@sparta에게 질문할 수 있습니다. 슬랙이나 구글링으로 방법을 찾을 필요가 없습니다.
