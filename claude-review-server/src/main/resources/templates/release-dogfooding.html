개밥먹기 기록

리뷰 서버가 스스로를 리뷰하기까지의 과정

개밥먹기란?

Eating your own dog food — 자기가 만든 제품을 직접 사용하면서 문제점을 체감하고 개선하는 개발 문화입니다.

적용 대상리뷰 서버 저장소 (your-username/claude-review)
적용 방식수강생과 동일한 ai-review.yml + GitHub Secrets
검증 항목자동 리뷰, @sparta 대화, 업데이트 공지
날짜2026-04-16

도입 배경

수강생들에게 AI 코드리뷰 서비스를 제공하면서, 정작 서비스 자체의 코드 품질은 AI 리뷰 없이 관리되고 있었습니다.

수강생 PR → ai-review.yml → 리뷰 서버 → AI 리뷰 코멘트
리뷰 서버 PR → (리뷰 없음) → 직접 머지

수강생이 겪는 모든 UX를 개발자도 직접 겪어야 서비스 품질을 높일 수 있다고 판단했습니다.

1

개밥먹기 설정

GitHub Private Repository 등록 + Secrets 설정
1
Private Repository 생성

your-username/claude-review 저장소를 Private으로 생성하고 전체 프로젝트 코드를 push했습니다.

2
GitHub Secrets 등록 
REVIEW_SERVER_URL = https://review.example.com
REVIEW_SECRET     = (인증 키)

수강생들이 설정하는 것과 동일한 시크릿 값을 등록했습니다.

3
ai-review.yml 워크플로우 등록

.github/workflows/ai-review.yml에 최신 버전(대화형 응답 포함)을 배치했습니다.

on:
  pull_request: [opened, synchronize]
  issue_comment: [created]
  pull_request_review_comment: [created]
2

첫 번째 개밥먹기 — 기능 개선 PR

your-username/claude-review#2
PR 생성: 대화 기능에서 전체 리뷰 제거

기능 브랜치에서 ConversationService를 수정하고 PR을 열었습니다.

AI 코드리뷰 자동 생성

PR 생성 즉시 Actions가 트리거되어 AI 리뷰가 코멘트로 등록되었습니다.

## 🤖 AI 코드리뷰

> **[업데이트 확인](...)** — 대화형 Q&A 강화

### 🟡 개선 제안
1. 하드코딩된 안내 메시지 분리
2. Fallback 서비스 의존성 누락 검증
첫 번째 문제 발견: 업데이트 링크 새창 미작동

AI 리뷰의 업데이트 링크가 새창으로 열리지 않았습니다.

원인: GitHub 마크다운에서 <a target="_blank"> 미지원

해결: 마크다운 링크 [text](url)로 변경

두 번째 문제 발견: @sparta 멘션 응답 실패

PR 코멘트로 @sparta 멘션 후 AI 답변이 오지 않았습니다.

원인: ${{ github.event.comment.body }}에 괄호가 포함되어 쉘 syntax error 발생

해결: env: 블록으로 안전하게 변수 전달

# Before (위험)
BODY="${{ github.event.comment.body }}"

# After (안전)
env:
  COMMENT_BODY: ${{ github.event.comment.body }}
run: |
  BODY="$COMMENT_BODY"
개밥먹기로 발견한 문제 2건 수정 후 정상 동작 확인

업데이트 링크 새창 수정 + 쉘 특수문자 수정 후 @sparta 멘션이 정상 응답했습니다.

개밥먹기 성과

1. 실사용 환경에서 2개의 버그를 즉시 발견

curl 테스트로는 발견할 수 없었던 문제를 실제 GitHub 환경에서 즉시 발견했습니다. 마크다운 렌더링 차이와 쉘 특수문자 처리는 실제 사용 환경에서만 체감할 수 있는 이슈입니다.

2. PR 기반 워크플로우 확립

이제 리뷰 서버의 모든 변경사항은 PR을 통해서만 main에 반영됩니다. PR마다 자동 AI 리뷰가 달려 코드 품질이 지속적으로 검증됩니다.

3. 수강생과 동일한 경험

항목수강생리뷰 서버
워크플로우ai-review.yml동일
리뷰 서버review.example.com동일
자동 리뷰PR opened/synchronize동일
대화 Q&A@sparta 멘션동일
업데이트 공지리뷰 코멘트에 표시동일

개밥먹기 아키텍처

  → GitHub Actions (ai-review.yml)
    → Cloudflare Tunnel
